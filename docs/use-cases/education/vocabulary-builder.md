# Vocabulary Builder

## Description
Deepen understanding of any word by exploring its definition, etymology, pronunciation, usage examples, synonyms, antonyms, register (formal/informal), common collocations, and memory hooks. Goes far beyond a dictionary entry to make words stick.

## Why Hermes
Word acquisition is most effective when a learner encounters a word in multiple contexts with meaningful associations. Hermes generates rich, contextually accurate examples across varied registers and provides etymological hooks that make words memorable.

## Quickstart
```bash
python examples/education/learning_assistant.py vocab --word "ephemeral" --examples 5
```

## Sample Input
```
Word: ephemeral
Examples: 5
```

## Output Format
```
WORD: ephemeral
Pronunciation: ih-FEM-er-ul
Part of speech: adjective
Register: Formal/literary

DEFINITION
Lasting for a very short time; transitory.

ETYMOLOGY
From Greek "ephemeros" (ἐφήμερος) — epi (on) + hemera (day) — literally "lasting only a day." Originally used in botany for flowers that bloom for a single day.

EXAMPLES IN CONTEXT
1. [Literary] "The ephemeral beauty of cherry blossoms draws millions to Japan each spring."
2. [Academic] "Social media trends are largely ephemeral, disappearing from public consciousness within days."
3. [Everyday] "Her fame proved ephemeral — one viral video, then silence."
4. [Scientific] "Mayflies are among the most ephemeral of insects, living only 24 hours as adults."
5. [Business] "The ephemeral nature of consumer attention makes brand loyalty increasingly difficult to sustain."

SYNONYMS: fleeting, transient, momentary, short-lived, transitory, passing
ANTONYMS: permanent, enduring, eternal, lasting, perpetual

COLLOCATIONS (common word pairings)
ephemeral + beauty / pleasure / fame / trend / nature / experience

MEMORY HOOK
"Ephemeral" contains "hemer" (day in Greek). Think: "this lasts only a day."

USAGE WARNING
Do not confuse with "ethereal" (delicate, heavenly in quality) — similar sound, very different meaning.
```

## Tips
- Use `--examples 10` for comprehensive coverage before an exam or writing assignment.
- Add `--context academic` or `--context business` to generate domain-specific examples.
- Ask for a whole word family: `"give me all forms of 'ephemeral' — noun, verb, adverb"`.
- Combine with the flashcard generator to automatically create vocabulary cards.
